# example-project — Capitão Arthur vs o Temível Senhor Satã

Projeto cobaia: um filme curto passado por produção para **derivar o fluxo de
trabalho pela experiência**, em vez de desenhar ferramentas primeiro. Faz parte do
estudo em `../methodology_study.md`.

- Original: `Cap_Arthu_vs_o_Temivel_Senhor_Satã.pptx` (fora do git, ver `.gitignore`)
- Filme todo em CG, com captura de movimento; arquivos em português.

| Arquivo | O que é | Quem edita |
|---|---|---|
| `historia/argumento.md` | Transcrição literal do .pptx | ninguém (refeita a partir do .pptx) |
| `historia/sequencias.md` | Quebra em sequências + ligações setup/payoff | agente propõe, Rafael aprova |
| `historia/questoes.md` | Questões de história apontadas pelo continuísta | agente aponta, Rafael responde |
| `diario-de-atrito.md` | Onde a metodologia falhou e o que foi decidido | agente, a cada etapa |

## Etapas

1. ~~Argumento → sequências~~ (feito)
2. Plano de captura + planos por sequência ← **próxima**
3. Cenários, props, personagens (com linha do tempo de estados)
4. Storyboard
5. Pedidos de mudança do diretor → reconstrução seletiva → rollback

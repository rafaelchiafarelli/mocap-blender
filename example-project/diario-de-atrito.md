# Diário de atrito

Cada vez que a metodologia (`../methodology_study.md`) não deu conta, ou foi preciso
inventar um arquivo, campo, papel ou etapa, entra aqui: o que aconteceu e o que foi
decidido. No fim, este diário vira o fluxo de trabalho, e cada item vira
iniciativa, épico ou tarefa.

| # | Atrito | Decisão |
|---|---|---|
| A1 | Precisamos de uma **bíblia** do filme (look, luz, paleta, materiais, regras de câmera) acima de tudo; aqui ela já existe nos slides 7–11 (Expressionismo alemão, P&B) | Criar a unidade "bíblia". Mudanças genéricas ("deixa com cara de anos 70") só entram nela, ou são recusadas |
| A2 | Questões de história que o agente aponta mas não pode resolver | O fluxo do filme também segue iniciativas → épicos → tarefas, como este repo. Por enquanto: `historia/questoes.md` |
| A3 | Dependências de história entre sequências (setup/payoff) não são entradas de arquivo | Declarar ligações (`historia/sequencias.md`). Provavelmente um agente continuísta precisa ser criado |
| A4 | A chamada coloca o covil dentro de 010 e 040; o estado da Iori avança ao longo do filme | Os cenários têm uma **linha do tempo de estados**. Detectar o que pode ser gravado como uma parte e montado depois |
| A5 | A Inteligência é personagem sem corpo (voz + aparelho de pulso) | Por enquanto, tipo "voz/aparelho". Mais tarde: corpo holográfico |
| A6 | Voo no espaço não tem contato com o chão | O ator fica sobre um **apple box**. Cada take registra **o que está ligado ao chão e o que é o chão** (apple box ≠ chão do cenário) |
| A7 | Ordem do filme ≠ ordem de gravação: para os atores é melhor gravar em sequência e montar depois | Separar **plano de captura** (blocos de atuação contínua) de **planos do filme** (que recortam trechos dos takes) |
| A8 | O filme é todo em CG, mas projetos futuros serão híbridos | Não construir agora, mas não fechar a porta: cada elemento de um plano declara se é **CG ou placa filmada** |
| A9 | O `.pptx` (original do Rafael) é binário | Fica fora do git (`.gitignore`); `historia/argumento.md` é a transcrição literal, refeita quando o .pptx muda |

## 2. Sketchfab

- **Depends on:** versioning
- **Contract:**
  - In: Sketchfab through BlenderMCP (account + API key)
  - Requires: only models whose license allows use in the film; source, author and license stored with the file

- **Out of scope:** rigging it (characters/3)
- **Tests:** manual agent session; license recorded next to the file
